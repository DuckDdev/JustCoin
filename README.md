# 🪙 JustCoin

> Telegram-бот виртуальной валюты «ДжастКоин» на Python и aiogram.

**JustCoin** — игровой Telegram-бот с собственной экономикой: пользователи получают коины, участвуют в глобальном рейтинге, открывают магазин, используют промокоды и оформляют карточку профиля. Для управления проектом предусмотрена отдельная админ-панель.

> Полный справочник функций и команд находится в [docs/FEATURES.md](docs/FEATURES.md).

## Возможности

- 🪙 получение коинов с кулдауном и настраиваемой наградой;
- 📦 случайный курьер с посылками;
- 🏆 глобальный топ игроков;
- 📊 карточка статистики 900×500 с аватаром, балансом, рейтингом и историей;
- 🎟️ промокоды;
- 🎨 «Джасгнит» — магазин тем оформления карточки;
- 🛒 магазин апгрейдов;
- 🪪 JustID — короткие ссылки на профили вида `$John`;
- 🏅 статусы игроков: создатель, админ, VIP и донатор;
- 🐌 система «Замедлись» после простоя бота;
- 🚫 временные и бессрочные блокировки;
- 📢 массовые объявления;
- 🛠️ админ-панель;
- 🔧 режим технических работ;
- 🔗 ссылки для товаров и самого бота;
- 💾 SQLite с миграциями и транзакциями;
- 🧪 локальные unit/integration-style и E2E проверки.

Баланс, статистика, посылки и другие данные игрока привязаны к **Telegram `user_id`**, а не к конкретному чату. Один игрок использует один кошелёк во всех беседах, где работает бот.

## Команды

### Публичные

| Команда | Описание |
|---|---|
| `/jcoin` | Получить джаст коины |
| `/jtop` | Глобальный топ |
| `/jstats` | Статистика и карточка |
| `/jasgnight` | Магазин тем |
| `/theme <тема>` | Выбрать купленную тему |
| `/setid <имя>` | Установить JustID |
| `/myid` | Показать свой JustID |
| `/id $John` | Открыть карточку игрока |
| `/promo <код>` | Активировать промокод |
| `/help` | Список команд |

Алиасы:

- `/justcoins` → `/jcoin`
- `/top` → `/jtop`
- `/stats`, `/profile`, `/me` → `/jstats`
- `/jg` → `/jasgnight`

Бот также понимает некоторые текстовые триггеры: «Джасткоины», «Топ», JustID вида `$John` и промокоды.

### Административные

| Команда | Описание |
|---|---|
| `/apanel` | Открыть админ-панель |
| `/ban <игрок> [срок] [причина]` | Заблокировать игрока |
| `/unban <игрок>` | Снять блокировку |
| `/bans` | Активные блокировки |
| `/announce <текст>` | Рассылка по найденным чатам |
| `/setstatus <игрок> <статус>` | Выдать или снять статус |
| `/maintenance_on <функция> <причина>` | Включить техработы |
| `/maintenance_off <функция>` | Отключить техработы |
| `/maintenance_status` | Посмотреть состояние функций |
| `/jpromo` | Управление промокодами |
| `/jgrant` | Выдать апгрейд |
| `/jinstant` | Управление мгновенным получением |

Игрока можно указывать через JustID, @username, числовой Telegram ID или ответом на сообщение.

## JustID

JustID выглядит как короткое имя:

`$John`

Регистр не имеет значения. Занятое имя нельзя перехватить, а освободить его можно через:

```text
/setid off
```

Зарезервированные системные имена определяются в `bot/config.py` через `JUSTID_RESERVED`.

## Джасгнит

«Джасгнит» — магазин тем карточки профиля.

Доступны темы:

| Тема | Цена |
|---|---:|
| `default` | бесплатно |
| `ocean` | 150 |
| `emerald` | 150 |
| `midnight` | 180 |
| `crimson` | 200 |
| `sunset` | 220 |
| `gold` | 250 |
| `royal` | 300 |

Покупка сохраняется навсегда. Тему можно менять сколько угодно раз.

## Админ-панель

`/apanel` объединяет основные административные функции:

- технические работы;
- промокоды;
- создание товаров;
- управление темами;
- баны;
- статусы;
- ссылки;
- отправка сообщений в найденные чаты;
- статистика.

Созданные товары могут иметь описание и несколько ссылок. Для ссылок принимаются только безопасные схемы `http`, `https` и `tg`.

## Блокировки

Примеры:

```text
/ban $John
/ban $John 30м флуд
/ban @john 12h спам
/ban 12345 7д
/ban $John 4w
```

Поддерживаются минуты (`м`), часы (`h`), дни (`д`) и недели (`w`/`н`). Без срока бан бессрочный.

Администраторы защищены от случайной блокировки, включая попытку заблокировать самого себя.

## Промокоды

Промокоды хранятся в SQLite и могут управляться без изменения исходного кода:

```text
/jpromo <код> <монет> [лимит]
/jpromo off <код>
/jpromo on <код>
/jpromo list
```

Повторная активация одного промокода одним пользователем невозможна.

## Магазин апгрейдов

Секретный магазин открывается командой `/jshop` (также `/jupgrade`) при наличии специальных монет.

Примеры апгрейдов:

- x2;
- x3;
- уменьшение кулдауна;
- мгновенное получение — только для выдачи администратором.

Апгрейды покупаются атомарно, поэтому повторное нажатие кнопки не должно списать валюту дважды.

## Установка

### Требования

- Python **3.13+**;
- pip;
- Telegram Bot Token.

### 1. Клонирование

```bash
git clone https://github.com/DuckDdev/JustCoin.git
cd JustCoin
```

### 2. Виртуальное окружение

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Для Windows:

```powershell
.venv\Scripts\activate
```

### 3. Зависимости

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Конфигурация

Создайте `.env` из примера:

```bash
cp .env.example .env
```

Минимально нужны:

```ini
BOT_TOKEN=your_bot_token
ADMIN_IDS=123456789
```

Дополнительные параметры находятся в `.env.example`.

**Никогда не публикуйте настоящий `BOT_TOKEN` или файл `.env`.**

### 5. Запуск

```bash
python main.py
```

## Конфигурация

Основные параметры:

| Переменная | Значение по умолчанию | Назначение |
|---|---:|---|
| `BOT_TOKEN` | — | токен Telegram-бота |
| `ADMIN_IDS` | — | ID администраторов |
| `CREATOR_IDS` | — | ID создателей |
| `CLAIM_COOLDOWN_SECONDS` | `10800` | кулдаун получения |
| `CLAIM_MIN_AMOUNT` | `1` | минимальная награда |
| `CLAIM_MAX_AMOUNT` | `5` | максимальная награда |
| `COURIER_CHANCE` | `0.01` | шанс курьера |
| `TOP_SIZE` | `10` | размер топа |
| `ANTISPAM_COOLDOWN` | `1` | антиспам в секундах |
| `DB_PATH` | `justcoin.db` | путь к SQLite |

Полный список параметров и комментарии находятся в `.env.example`.

## Тестирование

JustCoin содержит два локальных тестовых сценария:

```bash
python run_tests.py
python run_e2e.py
```

`run_tests.py` проверяет основную бизнес-логику, SQLite, экономику, промокоды, апгрейды, JustID, темы, статусы, баны, техработы и другие сервисы.

`run_e2e.py` проверяет взаимодействие через Dispatcher aiogram без необходимости отправлять реальные запросы Telegram.

## База данных

Проект использует SQLite через `aiosqlite`.

Основные данные включают:

- пользователей и балансы;
- посылки;
- промокоды и их активации;
- купленные темы;
- ссылки;
- найденные чаты;
- блокировки;
- пользовательские товары;
- состояние технических работ.

Миграции выполняются при запуске.

## Надёжность

JustCoin старается не падать из-за одной ошибки обработчика. Ошибки логируются, а пользователю возвращается безопасное сообщение.

Операции с валютой выполняются транзакционно, чтобы повторные нажатия и параллельные запросы не приводили к двойному начислению или списанию.

## GitHub Actions

Workflow запускается при изменениях в `main` и при pull request'ах.
